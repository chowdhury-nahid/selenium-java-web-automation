# CLAUDE.md — selenium-java-web-automation

## What this is
Java-based Selenium WebDriver framework for automated web testing. Demonstrates common web interactions, best practices, and scalable test structure.

## Tech stack
- Java 17+, Selenium WebDriver 4.0+
- Maven 3.8+ for build
- MIT License

## Project structure
- `src/test/java/` — test classes
- `src/main/java/` — page objects and utilities
- `pom.xml` — Maven config
- `target/` — build output

## Commands
```bash
mvn clean test           # run all tests
mvn test -Dtest=ClassName # run specific test class
```
